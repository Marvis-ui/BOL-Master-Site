# Fellowship & Memories albums

Edit the album entries at the top of `gallery-albums.js`. Set `driveUrl` to the matching Google Drive folder URL when ready. Empty or unsupported URLs display Album coming soon, with no link. Existing categories: Special Events, Chess Championship, Annual Picnic.

Upload and manage photographs directly in Google Drive. Keep folders Restricted, and grant viewers access or approve their requests in Google Drive. The website cannot configure or enforce Drive sharing permissions. Covers are public, so use only images suitable for public display.

The site no longer reads or writes the old browser-local gallery albums. Existing browser storage has not been deleted. The card grid, page banner, and navigation are preserved; upload/delete controls and the local photo viewer have been removed.
