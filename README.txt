BEACON OF LIGHT (BOL) — WEBSITE
Built by Marvelous

FOLDER OVERVIEW:
- index.html         -> Homepage (Banner, Core Pillars, Interactive Bible Quiz, Daily Quote)
- about.html         -> Church vision, Hour of Power info, and weekly service rhythm
- calendar.html      -> Auto-calculating yearly calendar (handles fixed dates, rules, and TBA events)
- celebrations.html  -> Synced weekly/monthly birthdays and church milestones
- daily-quotes.html  -> Automatic daily scripture feed with reaction buttons
- sermons.html       -> Filterable & searchable sermon notes archive
- chess.html         -> Annual August Round-Robin Chess Championship hub & sign-up roster
- gallery.html       -> Category-filtered multi-photo event albums
- contact.html       -> Church info & message/prayer request form

KEY CONTROL FILES:
1. boldata.js
   - Single source of truth for BOTH calendar.html and celebrations.html.
   - Add/edit birthdays, fixed holidays, recurring rules (e.g., 1st Sunday), or TBA events here.
2. bolwebstyle.css
   - Shared styling, colors, sticky footer, mobile layout, and smooth page transitions across all 9 pages.
3. images/
   - Drop real event photos here matching the filenames in gallery.html (e.g., anniversary1.jpg, picnic1.jpg).
